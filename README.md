# Kajal Lakra — Portfolio

A premium, responsive single-page portfolio designed for GitHub Pages.

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Deploy to GitHub Pages
1. Create a GitHub repository named `portfolio` (or any name).
2. Upload `index.html`, `style.css`, `script.js`, and `assets/`.
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch** → `main` → `/root`.
5. Save. Your site will be available at `https://kajal-lakra.github.io/portfolio/` if the repository is named `portfolio`.
